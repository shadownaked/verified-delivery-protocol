| 操作 | 实际命令 | 包含范围 |
|---|---|---|
| 安装依赖 | _（本模板包无运行时依赖，仅需 sh / grep / find / wc）_ | — |
| 全量测试 | `sh scripts/test.sh` | 核心文件存在性、铁律 F1–F20 连续、阶段 P0–P7、门禁/发布清单项数、VDP 标识覆盖、产物新鲜度、空目录、旧名残留 |
