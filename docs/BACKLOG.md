## 2. 评估规则（每个想法进入当前任务前先回答）

1. 它属于本版 MUST 吗？
2. 不做会阻止交付吗？
3. 现在做的收益是什么？
4. 会增加哪些风险？
5. 是否挤占已承诺任务？
6. 能否推迟到下一版？

默认决策：
- 阻止本版验收 → 纳入当前任务。
- 不阻止验收、低风险且成本明确 → 按授权判断。
- 扩大范围或改变合同 → **必须批准**。
- 仅因"看起来更优雅" → **不自动纳入当前版本**。
