## 2. KPI 选取指南

应覆盖四类，按项目性质取舍：

| 类别 | 典型 KPI |
|---|---|
| 功能 | 成功率、正确率、覆盖场景通过数 |
| 体验 | P50 / P95 时延、交互步数 |
| 稳定 | 错误率、卡死率、恢复成功率 |
| 资源 | 内存峰值、成本、调用次数 |

## 3. 硬门规则

- 任何变更后 KPI 恶化 > **[10%]**（或缺失测量）→ 门禁不通过。
- 接受恶化必须：**ADR + 用户明示同意**，并记录补偿条件与到期日。
- 不能自动测量的 KPI，用固定场景清单人工测量并记录，同样入表 —— 不得因为"不好测"就不测。

## 4. 测量纪律

- 样本量、成功与失败的计入方式必须写明。
- 与哪个基线比较、允许多大波动必须写明。
- 样本不足时明确标为**探索性结果**，不得据此下确定性结论。
- 每次测量记入 `docs/BASELINES.md`。
